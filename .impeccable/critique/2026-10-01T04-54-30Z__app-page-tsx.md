### Remaining Issues

**[P2] Inter is the only typeface (4 detector findings)**
- The detector flags Inter as overused. For a product named 栞 (bookmark) with a Japanese stationery identity, a more distinctive display face would strengthen the brand. The body text can stay Inter; the display headings (hero title, section titles) want a face with more character.
- **Fix**: Source a display face from Google Fonts that fits the warm/craft aesthetic — candidates: Shippori Mincho (Japanese serif), Noto Serif JP, or a warm rounded face like Nunito for the display sizes. Keep Inter for body.
- **Suggested command**: `/impeccable bolder` (scoped to typography)

**[P2] Secondary jenjang cards have no icons**
- The primary cards (SD/SMP/SMA/SMK) have SVG icons, but the secondary cards (Madrasah, AKM & P5, Produktif, etc.) show only name + count. The visual hierarchy works, but the secondary tier looks incomplete compared to the primary tier.
- **Fix**: Add simpler SVG icons or colored initial-letter badges consistently across all secondary cards.

**[P3] No empty state for zero books**
- If the database has zero books, the page shows "0 Buku Tersedia" and an empty grid. No fallback message exists.
- **Fix**: Conditional render: if `totalBooks === 0`, show a friendly empty state message.

**[P3] `Madrasah` key mismatch risk**
- The `JENJANG_META` map uses key `'MADRASAH'` but the actual database value for Madrasah may be `'Madrasah'` (mixed case). If keys don't match, the card falls through to the default label/color. This was inherited from the original code but is worth verifying.
